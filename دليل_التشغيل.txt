ميزانية أسرتي - دليل الإعداد بعد ربط Firebase
=============================================

تم إدخال إعدادات مشروع Firebase الذي أنشأته داخل index.html. لا تحتاج إلى نسخ الإعدادات مرة أخرى.

المشروع المرتبط: myfamilybudget-b76ef

الخطوة 1: تفعيل تسجيل الدخول بالبريد وكلمة المرور
1) افتح https://console.firebase.google.com/
2) اختر مشروع MyFamilyBudget.
3) من القائمة افتح Build ثم Authentication.
4) اضغط Get started إذا ظهرت.
5) افتح Sign-in method أو Providers.
6) اختر Email/Password، فعّل الخيار الأول ثم Save.

الخطوة 2: إنشاء قاعدة بيانات Firestore
1) من القائمة افتح Build ثم Firestore Database.
2) اضغط Create database.
3) اختر Start in production mode.
4) اختر موقع قاعدة البيانات. اختر موقعاً قريباً وثبّت اختيارك؛ لا يمكن تغييره لاحقاً بسهولة.
5) بعد الإنشاء افتح تبويب Rules.
6) استبدل القواعد الموجودة بمحتوى ملف firestore.rules المرفق ثم اضغط Publish.

قواعد الحماية الموجودة في الملف تسمح فقط للمستخدم المسجل بقراءة وكتابة بيانات مساحة الأسرة المرتبطة بمعرّف حسابه. لا تجعل القواعد مفتوحة للجميع.

الخطوة 3: نشر التطبيق على رابط مجاني
يجب رفع الملفات التالية كما هي إلى استضافة HTTPS مجانية: index.html و manifest.json و sw.js و icon.svg. يمكن استخدام GitHub Pages من متصفح الهاتف، لكن ستحتاج إلى حساب GitHub وإنشاء مستودع ورفع الملفات من المتصفح. لا ترفع ملف firestore.rules إلى جذر الموقع؛ استخدم محتواه في صفحة Rules داخل Firebase.

بعد ظهور رابط GitHub Pages: من Firebase > Authentication > Settings > Authorized domains أضف نطاق الموقع (مثلاً username.github.io).

الخطوة 4: إنشاء الحساب والتثبيت
1) افتح رابط التطبيق المنشور في Chrome.
2) اضغط إنشاء حساب الأسرة لأول مرة، واستخدم بريد الأسرة وكلمة مرور قوية.
3) بعد الدخول اختر من قائمة Chrome تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
4) افتح الرابط نفسه على هاتف الزوجة وسجّل الدخول بنفس الحساب. لا تنشئوا حساباً ثانياً.

ملاحظات أمان وتشغيل
- إعدادات Firebase الخاصة بتطبيق الويب تتضمن apiKey وهي ليست كلمة مرور؛ الحماية الفعلية تعتمد على Authentication وقواعد Firestore المنشورة بشكل صحيح. لا تشارك كلمة مرور الحساب.
- لا تبدأ بتسجيل بيانات مالية حقيقية قبل إكمال خطوات Authentication وFirestore ونشر قواعد الحماية.
- قائمة المشتريات والملاحظات محفوظة في مجموعة مستقلة ولا تدخل في حساب الإيرادات أو المصروفات.
- المزامنة تحتاج اتصال إنترنت.
- الخطة المجانية لها حدود استخدام وقد تتغير شروطها؛ راقب صفحة Usage and billing ولا تفعّل خطة مدفوعة.
- احتفظوا بنسخة احتياطية دورية من بياناتكم.
